# Netflix Movie's and Tv Show Data Analysis using SQL
🎬 Netflix Data Analysis Project (SQL)
📌 Introduction

This project focuses on analyzing Netflix’s movies and TV shows dataset using SQL.
The goal is to extract meaningful insights that can help in understanding content trends, user preferences, and business decisions.

🎯 Objective
Analyze Netflix dataset using SQL
Perform data cleaning and transformation
Solve real-world business problems
Generate insights for better decision-making
🗂️ Dataset
Source: Netflix dataset (movies & TV shows)
Total Records: ~8000+
Key Columns:
Title
Director
Cast
Country
Release Year
Rating
Duration
Date Added
🛠️ Tools & Technologies
SQL (PostgreSQL / MySQL)
Excel (for initial exploration)
(Optional) Power BI for visualization
🧹 Data Cleaning Steps
Handled missing values in columns like director, cast, country
Converted date_added into proper date format
Extracted numeric values from duration
Removed duplicates (if any)
🔍 Business Questions Solved
What is the distribution of Movies vs TV Shows?
Which country produces the most content?
What are the most common ratings on Netflix?
How has content production changed over the years?
Who are the top directors with most content?
What is the average duration of movies?
Which genres are most popular?
📊 Key Insights
Movies are more in number compared to TV Shows
United States produces the highest amount of content
Content production increased significantly after 2015
Most common ratings are TV-MA and TV-14
Drama and International Movies are among the top genres
💡 Business Impact

The insights from this project can help:

Identify trending content types
Improve content investment strategies
Target specific regions for expansion
Enhance user engagement
